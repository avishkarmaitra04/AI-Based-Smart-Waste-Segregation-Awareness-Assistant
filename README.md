# AI-Based Smart Waste Segregation Awareness Assistant

## 📖 Project Overview
Improper waste segregation is a major environmental challenge in urban areas and educational campuses. Many individuals are unaware of how to correctly separate waste into wet, dry, and e-waste categories, leading to inefficient recycling, increased landfill usage, and environmental pollution.

This project presents an **AI-Based Smart Waste Segregation Awareness Assistant** that helps users identify the correct waste category and disposal method through a simple, rule-based AI approach.

## 🧠 Role of AI in the Project
The system uses **rule-based artificial intelligence** with keyword matching to classify waste items. It simulates an AI assistant by:
- Analyzing user input
- Identifying relevant keywords
- Classifying waste into Wet Waste, Dry Waste, or E-Waste
- Providing disposal guidance and sustainability tips
- Displaying a confidence score for transparency

No machine learning models or datasets are used, making the solution simple, explainable, and scalable.

## 🚀 Features
- Supports partial keyword matching
- Handles multiple user queries in a single run

## 🧪 How It Works
1. User enters a waste item
2. The system analyzes keywords in the input
3. Waste is classified into:
   - Wet Waste
   - Dry Waste
   - E-Waste
4. Disposal tips and confidence score are displayed
